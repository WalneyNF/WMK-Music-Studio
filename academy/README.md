# WMK Music Academy v0.1

Abra index.html no Chrome ou Edge. Não precisa compilar. Escolha uma aula, toque as teclas destacadas e repita no Queen's físico. Use o metrônomo para praticar. Os quatro timbres são síntese aproximada, não amostras do instrumento. A aula de acordes ensina notas separadas. Reconhecimento por microfone e MIDI ainda não implementados. Sintaxe JS validada; teste de áudio no navegador pendente.
