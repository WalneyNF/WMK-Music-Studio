# WMK Music Studio — direção técnica

Modo principal: navegador local, sem WebView2 obrigatório. Preservar código original e licença MIT. Groq e Ollama são os únicos provedores padrão de composição textual. Motores de áudio especializados ficam opcionais, sem downloads obrigatórios. Modelos de linguagem não sintetizam canto diretamente.

## Etapas
- [ ] Inicializador web e proxy local com logs e teste de saúde.
- [ ] Identidade WMK e português brasileiro.
- [ ] Integração Ollama /api/tags e /api/chat; Groq /openai/v1/chat/completions, chave somente no backend.
- [ ] Composição JSON validada, MIDI, ABC, acordes e reprodução.
- [ ] Academia integrada e importação de músicas.
- [ ] Teste Windows e publicação de pacote utilizável.
